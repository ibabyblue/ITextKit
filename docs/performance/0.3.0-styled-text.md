# ITextKit 0.3.0 Styled Text Performance

## Gate

- Package commit: `bd64ecbd9532f531cf68ea9bded0ae49c321bf8c`
- Test date: 2026-08-13
- Device: iPhone SE (3rd generation), `iPhone14,6`
- OS: iOS 26.5.2 (23F84)
- Build: Release, arm64, app-hosted XCTest
- Fixture: 20 rows and approximately 100 glyphs using a linear-gradient
  fill plus a 2 pt linear-gradient outward stroke
- Procedure: one warm-up run followed by three formal runs

The app-hosted suite uses internal counters without adding a public test seam.
Run its optimized device configuration with `-configuration Release
ENABLE_TESTABILITY=YES`; the normal library Release configuration remains
unchanged. The checked-in `ITextKitExample` scheme runs the same suite in
Debug for routine simulator regression.

The release gate passes. All formal test runs completed without a failure.

## Instruments results

The Release app was launched with `-ITextStyledPerformance`. This fixture
keeps 20 SwiftUI `ITextStyledText` rows moving continuously; every row combines
a linear-gradient fill and linear-gradient stroke.

Two 15-second recordings were attached to the running process:

- `styled-text-time-profiler-attached.trace`
- `styled-text-animation-hitches-attached.trace`

The Time Profiler run lasted 15.885 seconds and contained 1,498 samples at
1 ms each, equivalent to approximately 9.43% of one CPU core across the
process. The samples contained no sustained ITextKit drawing or glyph-path
hotspot. The separate animation counter test also proved that unchanged
animations caused zero layout and path rebuilds.

The Animation Hitches run lasted 15.788 seconds and reported:

- 0 animation hitches
- 0 potential hangs above the template's 33 ms threshold
- 59.57 displayed surface swaps per second on average over the 14 complete
  steady-state seconds
- 58 minimum and 60 maximum swaps in those steady-state seconds

The first and final partial seconds were excluded from the swap-rate average.
The exported trace tables and retained XCTest result bundles are the source of
the figures above.
