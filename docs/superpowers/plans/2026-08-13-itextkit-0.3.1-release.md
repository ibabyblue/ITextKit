# ITextKit 0.3.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish ITextKit 0.3.1 with complete Marquee behavior, performance, example, and installation documentation.

**Architecture:** Keep the already-verified public API and implementation unchanged. Update only consumer and maintainer documentation, validate the exact release tree, create one release commit and annotated tag, then atomically publish `main` and `0.3.1` and verify both remote refs resolve to the release commit.

**Tech Stack:** Swift Package Manager, Swift 5.10, UIKit, SwiftUI, Xcode XCTest, DocC, Git.

## Global Constraints

- Release version is `0.3.1`; tags have no `v` prefix.
- Preserve iOS 15 and Swift tools 5.10 minimums.
- Do not change public API or runtime implementation during documentation release work.
- Do not claim physical-device UI automation passed; it timed out before test initialization.
- Use an annotated tag and atomic push.
